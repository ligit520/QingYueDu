# 轻阅读 v0.4.0 更新说明

**发布日期**：2026-11-26
**版本号**：0.4.0（程序集 QingYueDu，项目 YueduPC）
**发布包**：`QingYueDu-v0.4.0-win-x64.zip`（自包含 win-x64，85.3MB，无需安装 .NET）

本次更新以 **PDF 阅读器** 和 **在线书闭环** 两大功能为核心，重构设置页结构，并修复了上个版本遗留的「在线书无法阅读 / 所有书打不开」等严重问题。数据格式与 v0.3.0 保持兼容，升级无需迁移、不会丢失原有数据（升级前仍建议先备份）。

---

## 一、新增功能

### 1. PDF 阅读器（完整引入）

内置 PDF.js 引擎（本地分发、完全离线可用），PDF 书走独立阅读器页面，与 TXT/EPUB 并列支持。

| 能力 | 说明 |
|------|------|
| 浏览 | 连续滚动模式，大 PDF 采用虚拟滚动（只渲染可见页 ±2），万页级大书滚动流畅不卡死 |
| 缩放 | 适应宽度 / 适应页面 / 自定义缩放，支持 Ctrl++ / Ctrl+- 快捷键，缩放状态记忆 |
| 侧边栏 | 文档目录（PDF outline）点击跳转、页面缩略图（限 400 页）、按页分组的批注列表（点击跳转 / 一键清空） |
| 文本标记 | 高亮 / 下划线 / 删除线，选中文字弹出快捷菜单 |
| 图形标记 | 矩形 / 椭圆 / 箭头，自由手绘与自由高亮，五色调色 |
| 批注存储 | 批注按页码 + 坐标独立存储，**不改动原始 PDF 文件** |
| 批注导出 | 按书导出为 Markdown 或 JSON |

导入对话框与文件夹批量导入均已支持 `.pdf`，导入时按格式自动分流到 PDF 阅读器。

### 2. 在线书闭环（加入书架即自动完成全链路）

针对「加入书架后还要手动逐章缓存、不知道有没有更新、换源后要重来一遍」的体验断层，形成完整闭环：

- **自动后台缓存**：从书城加入书架后，自动在后台串行缓存全部章节（串行队列 + 进度通知，不卡界面、可去重）；所有加入入口统一收口，换源成功后自动按新源重新缓存。
- **自动检测更新**：启动应用即后台检测所有已追更的书，发现新章节在书架顶部横幅提醒读者。
- **一键换源**：书源管理中可直接为在线书换源，换源成功后自动重新缓存新源正文。

### 3. 设置页分类重构

设置页原为单页长列表，现改为**二级结构**：

- 主页为 **8 个分类卡片**：外观 / 阅读 / 书源与传书 / 缓存管理 / 智能服务 / 数据与备份 / 快捷键 / 关于
- 点击卡片进入对应二级详情页（`Section` 折叠切换，直接引用控件）
- 详情页支持返回按钮 / Esc 键回主页

### 4. 默认阅读模式改为「左右翻页」

设置页「默认阅读模式」新增 **左右翻页** 选项（与上下滚动、双栏翻页并列），并设为默认值。阅读器内仍可随时通过底部翻页方式栏切换上下翻动 / 左右翻动 / 仿真翻页 / 覆盖翻页四种模式。

## 二、优化

- **大 PDF 性能**：PDF 阅读器从整书一次性渲染改为虚拟滚动，大文件内存占用与滚动流畅度显著改善。
- **在线书缓存体验**：缓存进度可视化（详情页 / 书架可看到缓存进度），后台串行队列避免并发抓取。
- **追更体验**：启动即后台检测更新，书架横幅提醒，不阻塞界面操作。

## 三、问题修复

### 严重问题：在线书无法阅读 / 所有书打不开（本次重点修复）

v0.3.0 之后出现「《斗破苍穹》打开没正文，随后所有书（含本地 TXT/EPUB）都打不开」的全局回归。根因是三个问题叠加，本次全部修复：

1. **XAML 解析期事件提前初始化 WebView2**：阅读器排版面板的亮度滑块 `Minimum="30"` 未设初值时，XAML 加载会把 Value 从 0 矫正到 30 并同步触发 `ValueChanged`，此时 WebView2 控件尚未创建，提前初始化导致失败。修复：滑块事件统一在 XAML 解析期拦截，页面导航完成后才放行。
2. **导航期预热 Core 导致永久挂起**：页面刚导航、WebView2 未进入可视化树时预热 Core 会永久挂起，阻塞正文加载。修复：移除导航期预热，回到「页面显示后自然初始化」的已知良好行为，并为 Core 初始化增加 15 秒超时兜底，失败时显示「正文渲染组件初始化失败」提示层（不再是无提示白屏）。
3. **书库加载任务被污染永久缓存**：书库加载完成后通知订阅者刷新书架时，若页面尚未就绪会抛异常，使加载任务变为失败态并被永久缓存，此后所有书都打不开。修复：加载任务改为可重建的缓存策略，通知派发逐个订阅者做异常保护。

### PDF 相关修复

- **批注划线后不显示**：批注创建后立即通知 JS 重绘，JS 侧同时做本地即时绘制，划线即时可见；修复缩放后批注坐标映射错位（下标读取错误）。
- **缩放异常崩进程**：缩放调用增加健壮的 JS 返回解析与空值保护，避免异步回调中的空引用异常直接导致进程崩溃。

### 其他修复

- **分页双栏阅读「多出来一部分字」**：跨栏章节定位改用全部分栏片段、前插章节滚动轴由纵向改为横向、动态追加强制重排、翻页步长读取实际列间距。
- 阅读器批注 / 目录 / 书签面板搜索框、目录每章字数显示等细节问题。

## 四、升级指引

1. **备份数据**（可选但推荐）：设置 → 数据与备份 → 一键备份，将全部书库与阅读数据备份为 zip。
2. **安装**：解压 `QingYueDu-v0.4.0-win-x64.zip` 到任意目录，运行 `QingYueDu.exe` 即可（自包含运行环境，无需安装 .NET）。
3. **数据兼容**：v0.4.0 数据格式与 v0.3.0 兼容，直接覆盖运行目录即可，原有书库、进度、书签、批注、设置均保留。
4. **PDF 使用**：将 `.pdf` 文件通过书架导入或拖入，即可在独立 PDF 阅读器中阅读与批注。
5. **在线书**：已有在线书在下次启动时会自动检测更新并按新逻辑缓存，无需手动操作。

## 五、已知说明
