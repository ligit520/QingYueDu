# 轻阅读 v0.5.0 更新说明

发布日期：2026-11-28

v0.5.0 是体验深化大版本，相对 v0.4.0 累积了 150+ 项增量改进，覆盖漫画、PDF、AI、TTS、主题、数据同步与阅读体验。数据格式保持兼容，升级无需迁移、不会丢失原有数据（升级前仍建议先备份）。

---

## 一、新增能力

### 1. 漫画阅读器（CBZ / CBR / ZIP）

| 能力 | 说明 |
| --- | --- |
| 格式支持 | CBZ / CBR / ZIP 导入，自动提取首页作封面 |
| 阅读模式 | 单页 / 双页 spread（奇偶页左右可调）/ 连续滚动 |
| 操作 | 左右翻页、50%~400% 缩放、适应宽度、双指缩放、方向锁定、翻页手势 |
| 性能 | 图片 FIFO 缓存（限 8 张 + 解码限宽 2400px）、预加载 ±2 页、连续滚动虚拟窗口只渲染视口附近 |
| 进度 | 页码进度持久化，与书籍进度统一 |

### 2. TTS 多音色分角色朗读

- 自动从章节对话提示语（「XX说道：」「XX问：」等 34 种动词）识别出场角色
- 逐角色分配不同音色：Web 引擎逐句切换系统语音，Edge 引擎逐句传音色 ID
- 阅读器 TTS 栏「声部」面板：一键开关、检测本章角色、逐角色音色分配，按本书记忆
- 同时新增 TTS 断点续读，下次听书从上次句子继续

### 3. AI 能力扩展

- 在全书总结 / 章节速读 / 多轮问答之外，新增「本章续写」「排版纠错」「人物关系提取」
- 用户自配端点 / Key / 模型，兼容 OpenAI / Claude / Gemini 等 Chat Completions 协议

### 4. 主题与配色

- **应用强调色**：设置页「外观」8 色色板（跟随系统 / 经典蓝 / 水墨青 / 青柠绿 / 暖阳橙 / 玫红 / 紫罗兰 / 钢灰）
- **自定义阅读配色**：阅读主题新增第 5 项「自定义」，排版面板取色器自定义背景色 / 文字色
- 阅读主题保持实时切换不丢位置

### 5. 阅读位置与排版记忆

- **位置快照**：读到章节 50% 自动生成书签（用户删除后不重建），换源后精确续读
- **排版偏好按本书记忆**：字号 / 字体 / 行距 / 段距 / 边距等按书保存，一键重置默认

### 6. 数据与同步

- **本地增量同步**：进度 / 书签 / 批注导出与导入对账
- **每日自动备份**：本地目录备份，保留最近 N 份
- **Wi-Fi 传书**：局域网浏览器传书到书架

### 7. 书源与在线书

- 书城多源合并搜索（去重 + 排序）、书源规则导入向导（可视化生成 Legado JSON）
- 书源可视化编辑：原始 JSON 编辑 + 实时校验 + 格式化 + 规则字段概览
- **段评**：书源定义 `ruleComment` 时，侧边栏「段评」标签查看 / 回复，按章缓存

### 8. PDF 增强

- 批注搜索与批注总览、划词「复制」、按页导出批注（每页一个 Markdown）

### 9. 阅读报告深化

- 年度阅读报告（亮点 + 时长榜 + 导出 Markdown）
- 阅读历程时间线（最近 30 天有记录日 + 当日书籍）
- 按小时段阅读分布（24h 柱状图 + 峰值时段摘要）

## 二、优化

- **设置页二级分类结构**：主页 9 个分类卡片（新增「隐私」），含隐私声明页
- **存储位置更改**：可查看 / 更改数据目录，自动复制数据到新位置
- **阅读体验**：自定义字体导入、亮度 / 色温调节、1~4 栏、覆盖样式、自适应颜色、文档模式、进度条拖拽跳转、宽窗口自动双栏
- **书籍管理**：多分组（一本书归入多个分组）、标签筛选、批量整理、卡片显示字数、章节已读 / 当前标记
- **漫画 / PDF 性能**：虚拟滚动，大文件滚动流畅

---

## 三、修复

- **「所有书都打不开」回归**：书库加载 Task 被异常污染永久缓存、XAML 解析期滑块事件提前初始化 WebView2、导航期预热 Core 永久挂起——三根因全部修复，并加逐订阅者异常保护与 Core 超时兜底
- **产物同步路径陷阱**：明确快捷方式目录需完整同步 XAML 编译产物（`Views/*.xbf`、`App.xbf`、`MainWindow.xbf`、`*.pri`），避免连接 ID 错位导致阅读器连接崩溃
- 漫画 XAML `ManipulationMode` 非法赋值、`Frame.CurrentSource` 不存在等编译期问题
- TTS 角色分声部正则常量约束、WinUI 3 颜色 API 缺失等兼容性问题

## 四、升级指引

1. 从 Releases 下载 `QingYueDu-v0.5.0-win-x64.zip`
2. 解压到一个新目录（不要覆盖旧版目录，以便回退）
3. 运行 `QingYueDu.exe` 即可，自动读取原有本地数据
4. 建议升级前在设置页做一次完整备份

数据全部存储在 `%LOCALAPPDATA%\YueduPC\`，与程序目录分离，升级不会丢失。

## 五、已知说明

- 段评功能依赖第三方书源定义 `ruleComment` 规则，内置书源未带段评规则时显示「本章暂无段评」
- CBR（真 RAR 格式）解析依赖系统支持，部分 RAR5 文件可能无法打开（建议转为 CBZ）
- AI / 翻译 / Edge TTS / 在线书源为联网功能，需用户自行配置，数据默认不上传服务器
- RSS 订阅、播客、云同步、社交内容生态、AI 思维导图 / 生图已明确不做，不纳入规划
